# 主板日志支持包

本目录供 STM32H723 主板使用，不加入 F405 接收工程。两种通信版本分别存放：

| 目录 | 底层发送 | 接收板配置 |
| --- | --- | --- |
| [USB](USB/README.md) | 原有 USB CDC 队列与 READY/ACK 握手 | `COMM_INTERFACE_USB` |
| [SPI](SPI/README.md) | SPI 主机 DMA 队列发送，应用显式控制接收板就绪 | `COMM_INTERFACE_SPI` |

选择一套目录加入工程及头文件路径，不同时编译两套同名日志、故障和告警文件。
USB 目录保留拆分前全部文件内容；SPI 目录保留上层日志接口并替换底层。
这两套均为接入用户主板工程的源码支持包，不是独立可烧录工程。

普通日志、事件告警、故障及 NMI 捕获的接入步骤见各目录说明。
SPI 默认不发送数据，须按说明确认接收板 DMA 就绪后显式允许发送。
